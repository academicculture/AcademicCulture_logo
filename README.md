# Brand Assets

This repository contains the official brand identity assets, including logos, symbols, and related visual materials.

## Brand Colors

The primary brand colors are:

| Color        | RGB             | HEX       |
| ------------ | --------------- | --------- |
| Primary Blue | `0, 48, 82`     | `#003052` |
| White        | `255, 255, 255` | `#FFFFFF` |
| Primary Red  | `152, 16, 62`   | `#98103E` |

These colors are part of the brand's visual identity and should be reproduced accurately when used.

## Logo

The logo files provided in this repository are original brand assets.

### File Structure

```text
AcademicCulture_logo/
├── logo.svg
├── logo.png
├── logo.pdf
├── source/
│   └── logo-source.svg
└── README.md
```

The files in `source/` are editable source files created with Inkscape. Other logo files are intended for general use and distribution.
